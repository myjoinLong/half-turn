# 首发 72 小时观察表

在发布时记录实际起始时间、版本、应用和来源。按北京时间自然日分别记录 D0、D1、D2。当前处于本地开发阶段，尚无商店曝光、活跃或收入数据。

| 观察项 | 分子 | 分母 | 来源 |
| --- | --- | --- | --- |
| 开玩率 | 首次滑行人数 | 同来源商店曝光人数 | 开发者后台与游戏事件 |
| 首局完成率 | 完成首次正式线路人数 | 首次开始正式线路人数 | 开始滑行、完赛 |
| 主动再跳率 | 摔倒后触发重试人数 | 摔倒人数 | 摔倒、失误后重试 |
| 第二局参与 | 主动开始第二局人数 | 完成首局人数 | 开始滑行 |
| 次日与第 2 日回访 | D1、D2 再次开玩人数 | 已满观察期的同日新增人数 | 按首玩日分组 |
| 每日同题参与 | 当日开始每日题人数 | 当日开玩人数 | 带 daily 题号的开始滑行 |
| 视频转化 | 点击、展示、完播、到账人数分别计算 | 上一步人数 | 入口与奖励事件 |
| 广告后继续 | 到账后再次滑行人数 | 到账人数 | 事件时间序列 |
| 展示强度、收入 | 展示次数、实际收入 | 当日活跃人数 | 广告后台与游戏事件 |

同一玩家同一天去重。上线后用实际可用的后台或经同意的私测记录核对，不把本地导出直接当作全量遥测。同曝光期、相近来源的五款基线应分别填样本量和分母。出现白屏、卡死、掉档或漏奖，先复现版本、线路及宿主，再核对存档和流水。故障广告位可在开发者后台停用或清空对应构建配置后重新打包。
