# 《再翻半圈》本地候选版验收记录

## 0.9.0-rc.5 角色与手机操控精修

- 用具有厚度的雪板、固定器、雪靴、分段四肢和头盔重绘滑手。抓板和松手时逐步切换手位。雪面接触计算检查模型顶点、边中点与跳台、落坡折点的交会，摄像机近处裁掉超出视野的面，旗杆受碰时弯折。
- 270 组姿态与雪面组合通过数值验证，覆盖六种抓板、两个高台与练习台的台沿和落坡，以及起跳、落地、侧滑和起身阶段。15 组模拟、几何、手势、旗杆与存档测试通过。
- 在 320×568、390×844、430×932 的触控浏览器预览中，完成了上滑冲刺、下滑压刃、触摸取消、空中左右换招和展体落地。主要按键触控范围至少为 44×44 像素，展开动作列表不移动主操作区。390×844 衣柜预览还验证了头盔和雪板都保留边距。证据见精修手机触控回归及角色与装备截图。
- 浏览器整局回归通过开场起身、巡回首线四跳完赛、回放、练习、当日赛和衣柜。Windows WebKit 通过 375×667 的画布触控、练习完赛和回看。全线路固定步回归通过 34 项、102 遍。
- 候选包为 388,623 字节。SHA-256 为 `ff9b5d383883e1fdf5497fdc9173d20fd0b8af8f51f7175008bc4369a872ad43`。手机真机及 TapTap 宿主的手感、帧率和安全区仍待验证。

## 复验入口

1. 项目目录执行 `npm ci`、`npm test`、`npm run build`。运行 `python tools/package.py` 生成 ZIP。包内根目录可直接部署到静态 HTTP(S) 服务。
2. `npm run preview -- --port 4187`。手机连同一 Wi-Fi，通过本机无线网卡地址访问。调试路径 `/?editor` 叠加起跳区和两条弹道。
3. `node tests/mobile.mjs`、`node tests/tour.mjs`、`node tests/loading.mjs` 依次验证触摸、经济、弱网及回退。用 `node node_modules/tsx/dist/cli.mjs tools/audit-courses.ts` 重算路线证据。
4. 商店图标、首屏、失误、落地及动图在 store/。图标和动图生成脚本为 tools/store.py，使用 Pillow 及项目触摸回归采集的帧。README 包含商店简介、内容描述和本地存档说明。
5. 私测者可在「滑行设置」导出事件。在电脑打开「私测看板.html」，选择每位测试者的最新导出，按版本、来源及首发三日窗口汇总。保留样本量，人工核对留存观察期。

本作尚未创建 TapTap H5 应用，广告位为空。账号创建、认证及收款资料、真实广告填充、私有二维码、商店客服与主体信息、平台审查及正式发布均待办理。榜单与云同步权限待核对，当前使用本机成绩及同题挑战。开发者资料见 [H5 广告指南](https://developer.taptap.cn/minigameapidoc/quick-start/mcp-guide/ad-integration-guide/) 和 [包体管理与自测](https://developer.taptap.cn/v3/cli/skills/taptap-package-management/)。
