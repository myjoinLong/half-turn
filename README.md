# 再翻半圈

当前候选版为 0.9.1-rc.3。按下文构建并打包后，可在 `release/` 找到 `half-turn-0.9.1-rc.3.zip`。本机私测事件可用 [私测看板](release/私测看板.html) 离线查看。模块精修、赛事和广告验收见[制作方案](制作方案.md)。

横屏滑雪。按住雪道或右下操作区，地面左右拖动走线，下滑压刃，上滑冲刺。左下保留独立压刃键、冲刺键和动作选择。横放手机开始滑行，转回竖屏时暂停。同一趟转回横屏后倒数续滑。极光开场的两座高台落差为 24 和 32 米。起跳前点「动作」可选抓板，空中按住左右滑可以换招，松手则展体。开场有落地辅助，完成后从松林山零分起步。

正式雪道练习转体、手动蹬伸、抓板和连续弯。失误后会侧滑卸力，按住可以更快撑地起身，随后从当前位置继续滑。电脑可用空格、左右方向键、下方向键和 Shift 对应抓板、走线、压刃和冲刺。每日赛使用统一配置，允许压刃走线和起身。

从「雪场 → 人机赛季」参加松林公开赛、峡谷大跳台分站与夜光总决赛。每站对手为 7 名本地虚拟滑手。资格赛和决赛均为两趟取最高分，前四晋级，同分共享名次。已结算的趟次和历站荣誉保存在本机。

滑行时点「雪场」打开全屏导航，顶部可直接去赛事、衣柜和纪录。需要短暂休息时点暂停键，恢复后从当前位置继续。赛前可转动赛道地图，衣柜可旋转试穿，雪板图案与实滑一致。

## 运行与打包

在本目录执行 `npm ci`、`npm run dev`。手机与电脑连同一局域网，打开 Vite 输出的 Network 地址。正式静态包执行 `npm run build`、`python tools/package.py`，使用 `npm run preview` 检查。压缩包根目录为 index.html，以 HTTP(S) 静态托管。开发和预览服务器通过不同端口隔离本地存档。Phaser 和素材随包分发。

`npm test` 验证确定性模拟、模型接触、触控状态、评分与存档事务。浏览器回归先启动 `npm run preview -- --port 4187`，再执行 `node tests/descent.mjs`、`node tests/precision-mobile.mjs` 和 `node tests/resort.mjs`。用 `node tests/ad-preview.mjs` 启动测试宿主，验证两个正式广告落点的回场与发奖。浏览器默认使用 Windows Edge，可用 BROWSER_EXE 指定 Chromium。`node node_modules/tsx/dist/cli.mjs tools/audit-descent.ts` 跑完各线路三种打法。滑行设置可导出最近的本机事件。

用 `node tests/season.mjs` 自启测试站，按固定步输入验证三站晋级、领奖、刷新接续、回放和淘汰。赛道或规则调整后，用 `node node_modules/tsx/dist/cli.mjs tools/build-season-field.ts` 重新生成本地对手成绩。

## 源码与素材

- src/sim/ski.ts 包含每秒 60 步的模拟和按距离细分的碰撞检测。录像按跳台记录按键变化的模拟步、起跳配置和连段。
- src/content/routes.ts 定义三座山、15 条线路、练习与北京时间轮换题。个人最佳保存在本机，每日同题使用固定装扮和初始连段。
- 衣柜支持试穿、收藏和雪票兑换，包含 16 块雪板、12 套雪服、8 种雪迹。装备为纯外观，购买后自动穿戴。
- 动态试穿与实滑共用八种雪迹的粒子图形。雪纹、压刃、起跳和落地效果按固定模拟步记录。滑行设置里的「轻量雪粉」会压低粒子数量，保留关键反馈。
- 六种抓板采用中文动作名。雪道、旗门、雪板和关节模型共用三维透视。整副模型按雪面修正接触，近处场景按相机视锥裁剪。抓板手位参考 [国际雪联单板动作表](https://www.fis-ski.com/DB/v2/tricks?discipline=SB&event=HP)。
- src/scenes/art.ts 为本作原创程序绘制的雪山、松林、滑手骨架、雪板与雪粉。音效由 tools/sounds.py 在本地合成，渲染使用系统字体。Phaser 和构建工具许可证见各自包内 LICENSE。
- 首发同时配置赛后雪票和极光巡游。TapTap 开通本作广告后，在 .env.production.local 填写 VITE_HALF_TURN_TICKETS_AD 和 VITE_HALF_TURN_AURORA_AD 并重新构建。两个入口在首开满 60 秒且完成首条正式线路后开放，每个北京时间自然日合计最多领取两次。提前关闭和无填充返回原界面。当前普通浏览器预览会隐藏未配置的广告入口。
- 首发候选必须补录 Android/iOS 支持入口的触控、后台恢复、20 分钟稳定性、10 Mbps 冷热启动，以及私有二维码验证。平台曝光、收入、认证状态和审核结果取开发者后台。

## 商店资料草稿

**再翻半圈** · 单指花式滑雪

再多翻半圈就能破纪录。你敢在哪一刻松手？沿松林、峡谷与极夜山脊滑行，在跳台前屈膝、松手起跳，空中收腿多转半圈。正滑和倒滑都能漂亮落地。三座山共十五条线路，另有三个自由练习台与北京时间轮换的每日表演赛。

内容为风格化体育竞技，失误表现为滑手跌入雪中。实际适龄分级、客服联系方式及主体资料由发行账号填写。成绩、装扮、票券和诊断事件保存在当前浏览器，清除网站数据会清除进度。事件导出由玩家主动触发。选择广告时由 TapTap 宿主提供视频服务，正式接入后按实际广告 SDK 和主体补全隐私政策。
